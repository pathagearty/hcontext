Method & limits

What the comparison does—and does not—prove

Controlled

Same conditions—not the same access path

Case, evidence universe, actor, tenant, site, snapshot, task, decision criteria, recommendation schema, and human authority are frozen. Direct Review uses fragmented source tools. The compiler uses the Context Core plus Decision Profile; assisted review receives only the Decision Packet.

Private

Score after results

The runtime paths do not receive expected answers. The synthetic evaluator reads its separate answer key only after both results exist.

Estimated

Cost is not billing

The app can estimate variable model cost from provider tokens and an approved pricing catalog. Azure Cost Management remains the later billing source of truth.

Bounded

Seagate-inspired, not Seagate-internal

Fifteen designed synthetic cases can reveal implementation and safety failures. They do not assert Seagate's internal workflow or establish production accuracy, compliance, or ROI.

Reusable

The core is not the packet

The persistent Manufacturing Context Core is shared and updateable. A Decision Profile specifies what a task needs. Each Decision Packet is only a case-specific, source-linked projection for one review.

Implemented

PostgreSQL graph semantics

Supabase stores canonical entities, typed relationships, provenance, authority, temporal validity, policy controls, reusable profiles, packet lineage, and update events. A dedicated graph database is not required for this bounded proof.
